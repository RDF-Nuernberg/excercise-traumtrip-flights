# Traumtrip Frontend

Simple frontend to display all flights from the Traumtrip database.
Einfaches Web frontend um alle Flüge aus der Traumtrip datenbank anzuzeigen, sowie neue Flüge hinzuzufügen.

## Setup

1. Stellen Sie sicher das Backend läuft:

   ```bash
   cd ../backend
   uv run main.py
   ```

   Das Backend sollte unter `http://127.0.0.1:5000` laufen.

2. Öffnen Sie die `index.html` im Browser,  oder nutzen Sie die Live Preview:

   - Rechtsklick auf `index.html` -> Copy Path. 
   - Diesen im Browser einfügen.

## Aufgabe

Der HTML und CSS part ist bereits fertig. 

Implementieren Sie die Logik zur Abfrage und Anzeige der Daten in den entsprechenden Javascript Dateien, wie in der Aufgabenstellung angegeben.
Falls nicht vorhanden müssen diese noch angelegt werden.
